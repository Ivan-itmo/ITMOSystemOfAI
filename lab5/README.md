# Лабораторная 5 — дерево решений

Бинарная классификация грибов: съедобный (`e`) / ядовитый (`p`).

## Реализация

- исходный UCI Mushroom Dataset хранится локально в `data/`;
- из 22 признаков случайно выбираются `int(sqrt(22)) = 4` признака с фиксированным seed;
- пропуски `?` заменяются модой соответствующего признака, вычисленной по обучающей выборке;
- дерево небинарное: узел имеет отдельную ветвь для каждого категориального значения;
- дерево хранится через класс `TreeNode` и словарь дочерних узлов;
- критерий выбора признака — максимальный нормированный прирост информации (Gain Ratio): `Gain(X) / SplitInfo(X)`, где `SplitInfo(X)` — энтропия распределения объектов по ветвям; при нулевом `SplitInfo(X)` критерий равен нулю и разбиение по такому признаку не выполняется;
- Accuracy, Precision, Recall, ROC, PR и площади под кривыми вычисляются вручную;
- NumPy и Pandas используются для вычислений и данных, Matplotlib — только для графиков.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```
