# Лабораторная 5 — дерево решений

Бинарная классификация грибов: съедобный (`e`) / ядовитый (`p`).

## Реализация

- исходный UCI Mushroom Dataset хранится локально в `data/`;
- из 22 признаков используются `int(sqrt(22)) = 4`: заранее отобранные или случайные с фиксированным seed;
- пропуски `?` заменяются модой соответствующего признака, вычисленной по обучающей выборке;
- дерево небинарное: узел имеет отдельную ветвь для каждого категориального значения;
- дерево хранится через класс `TreeNode` и словарь дочерних узлов;
- критерий выбора признака — максимальный нормированный прирост информации (Gain Ratio): `Gain(X) / SplitInfo(X)`, где `SplitInfo(X)` — энтропия распределения объектов по ветвям; при нулевом `SplitInfo(X)` критерий равен нулю и разбиение по такому признаку не выполняется;
- Accuracy, Precision, Recall, ROC, PR и площади под кривыми вычисляются вручную;
- NumPy и Pandas используются для вычислений и данных, Matplotlib — только для графиков.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

## Выбор признаков

В `main.py` параметр `FEATURE_MODE` переключает режим:

- `"preselected"` (по умолчанию) — фиксированный список `PRESELECTED_FEATURES`;
- `"random"` — случайные четыре признака с `FEATURE_SEED`, как в исходном задании.

Заранее выбраны `odor` (запах), `gill-size` (размер пластинок),
`stalk-surface-above-ring` (поверхность ножки над кольцом) и
`spore-print-color` (цвет спорового отпечатка). Это четыре лучших отдельных
признака по Gain Ratio на обучающей выборке при `SPLIT_SEED = 67`, `TEST_SIZE = 0.2`.
Пропуски для ранжирования также заполняются только по обучающей выборке.
Тестовые метки при отборе не используются.

Команда `python select_features.py` перебирает все 22 признака и сохраняет их
оценки в `results/feature_ranking.txt`. Это ранжирование отдельных признаков,
а не полный перебор сочетаний и не гарантия лучшей совместной точности.
Скрипт не меняет фиксированный список автоматически; после изменения разбиения
можно повторить оценку и обновить `PRESELECTED_FEATURES` вручную.
`python main.py` перезаписывает метрики, дерево и графики для выбранного режима.
