# Лабораторная 4 — k-ближайших соседей

Классификация вин по трём классам методом k-NN.

## Структура

- `main.py` — подготовка данных, запуск двух моделей, статистика и графики.
- `knn.py` — реализация k-NN, accuracy и матрицы ошибок без sklearn.
- `data_utils.py` — разбиение, обработка пропусков, кодирование и масштабирование.
- `WineDataset.csv` — исходный датасет.
- `results/` — результаты запуска.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Windows:

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
```

## Модели

**Модель 1** использует 5 случайно выбранных признаков. Выбор фиксирован `seed=42`, поэтому результат воспроизводим.

**Модель 2** использует признаки:

- `Alcohol`
- `Flavanoids`
- `Color intensity`
- `OD280/OD315 of diluted wines`
- `Proline`

Проверяются `k = 1, 3, 5, 7, 10`.

## Обработка данных

- строки с отсутствующим целевым классом удаляются;
- числовые пропуски заменяются медианой обучающей выборки;
- категориальные входные признаки, если они появятся, кодируются one-hot;
- признаки стандартизуются по среднему и стандартному отклонению обучающей выборки;
- выборка делится на train/test стратифицированно, 75%/25%.

В текущем `WineDataset.csv` входные признаки числовые, пропусков нет, а `Wine` уже содержит метки классов `1`, `2`, `3`.

## Результаты

После запуска в `results/` создаются:

- `statistics.csv` — count, mean, std, min, 25%, 50%, 75%, max;
- `statistics_table.png` — таблица статистик;
- `feature_distributions.png` — распределения признаков;
- `features_3d.png` — 3D-визуализация;
- `evaluation.csv` — accuracy обеих моделей для разных `k`;
- `accuracy_by_k.png` — зависимость accuracy от `k`;
- `confusion_matrices_model_1_random.png`;
- `confusion_matrices_model_2_fixed.png`.

## k-NN

Для нового объекта считаются евклидовы расстояния до всех объектов обучающей выборки. Выбираются `k` объектов с минимальными расстояниями, после чего класс определяется большинством голосов. При равенстве голосов выбирается класс с меньшим средним расстоянием среди соседей этого класса.
